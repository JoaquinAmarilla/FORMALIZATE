# Formalizate

Formalizate es una plataforma móvil orientada a hacer visible y verificable la capacidad de trabajo de las personas, facilitar oportunidades laborales y conectar trabajadores, contratistas y contratantes.

## Estado del proyecto

El proyecto se encuentra en etapa de definición y preparación técnica. Este repositorio comienza con documentación funcional y técnica; todavía no contiene una aplicación implementada.

## Principio del producto

**El trabajador no tiene que demostrar que tuvo un empleo formal; tiene que poder demostrar que sabe trabajar.**

Formalizate debe permitir que personas con trayectorias formales, informales, mixtas o independientes presenten sus habilidades, experiencias, trabajos, formación y referencias.

## Roles principales

- **Trabajador:** busca empleo y presenta su identidad profesional.
- **Contratista:** ofrece servicios y puede organizar trabajos que requieran incorporar personas.
- **Contratante:** busca trabajadores o contrata servicios para una necesidad.

Una misma persona podrá activar más de uno de estos roles desde una sola cuenta.

## Criterio de trabajo

Las decisiones confirmadas, propuestas y pendientes deben mantenerse diferenciadas. No se debe implementar una funcionalidad que todavía no tenga requisitos y reglas suficientemente definidos.

## Alcance de lanzamiento

La primera versión priorizará una experiencia funcional y acotada: cuentas y roles, perfiles, habilidades, publicaciones y modalidades de contratación. Las funciones avanzadas se incorporarán por etapas.

## Idioma y convenciones

La documentación del producto se mantiene en español. Los nombres técnicos, identificadores, rutas y convenciones de código podrán utilizar inglés cuando sea una práctica estándar del ecosistema.
